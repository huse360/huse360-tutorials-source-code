# Código fuente — Canal de YouTube

Código fuente de los proyectos utilizados en los videos del canal [huse360](https://www.youtube.com/@huse360).

Cada proyecto corresponde a un video y es independiente de los demás.

## Estructura

Cada carpeta corresponde a la fecha de publicación del video

Dentro de cada proyecto encontrarás el código y los recursos correspondientes a ese video.

Cuando sea necesario, el proyecto incluirá una versión inicial y una versión final.

Para información adicional sobre cada proyecto, consulta la descripción del video correspondiente en YouTube.
